# Borocoxô

Site estático do projeto **Borocoxô**, desenvolvido para a MiniHacka 2026-1 da turma do 3º período de Redes de Computadores (Integrado).

## Ideia

Um site para quem está entediado e quer sugestões de filmes, séries, jogos, músicas ou atividades de acordo com o humor do momento.
