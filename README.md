# Borocoxô

Site estático do projeto **Borocoxô**, desenvolvido para a MiniHacka 2026-1 da turma do 3º período de Redes de Computadores (Integrado). Esta versão funciona como um exemplo genérico e temático do produto, com dados fictícios e uma prévia interativa.

## Ideia

Um site para quem está entediado e quer sugestões de filmes, séries, jogos, músicas ou atividades de acordo com o humor do momento.

## Exemplos temáticos

- **Humor do momento:** A pessoa escolhe se está animada, calma ou curiosa antes de receber ideias.
- **Tipo de entretenimento:** O filtro separa filmes, séries, jogos, músicas e atividades fora da tela.
- **Sugestão rápida:** Cada recomendação vem com duração, clima e motivo para escolher.
